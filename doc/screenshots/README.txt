截图补充说明
============

请将以下文件名的 PNG 截图放到本目录（与根目录 README.md 中的引用一一对应）：

1. workbench.png     收藏柜主界面（文件夹分组、搜索框、打开次数）
2. add-dialog.png    收藏对话框（文件夹下拉、仅收藏 / 收藏并打开按钮，建议暗色模式）
3. quick-pick.png    「快速打开收藏的表」命令面板
4. settings.png      StashBox 配置页（通路诊断、导入导出）

建议：宽度 1280px 左右；如条件允许，暗色与亮色各一张，可在 README 中追加 *-light / *-dark 链接。
